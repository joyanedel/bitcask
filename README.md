# BitCask

BitCask is a in-memory key-value database that store data in a append-only log storage.
Go to [Riak Documentation](https://docs.riak.com/riak/kv/2.2.3/setup/planning/backend/bitcask/index.html) for more information about BitCask

# What is this?

This is a kind of toy project that serves me as a playground for understanding depth concepts of filesystem API, how an application can read data faster using the proper api / system call an operating system provides.
This codebase is not meant to be used in any kind of system you are developing. So please refer to a real implementation of BitCask for such cases.
